**RaceDay — API Endpoint Plan**



This document lists every API endpoint planned for the RaceDay system based on the

entities and relationships defined in the ERD. Full detail includes HTTP methods, request/response

bodies, and role requirements.



**Resource Endpoints**



**Authentication**

\- Register a new user

\- Log in an existing user



**Users(Participant)**

\- Get a user's profile

\- Update a user's profile



**Events**

\- List all events

\- Get a single event

\- Create an event

\- Update an event

\- Delete an event



**Categories**

\- List categories for an event

\- Add a category to an event

\- Update a category

\- Delete a category



**Event Enrolments**

\- Enrol in a category

\- List a participant's own enrolments

\- List all enrolments for an event

\- Cancel an enrolment



**Results**

\- Capture a result for an enrolment

\- Get results/leaderboard for an event

\- Get a participant's own results
